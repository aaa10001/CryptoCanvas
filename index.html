雪崩效应

SHA-256 哈希函数具有雪崩效应——输入中一个比特的改变，会导致输出中约 50% 的比特发生变化。在 CryptoCanvas 中，这意味着 "Hello" 和 "hello" 会生成完全不同的画作。

🎨

算法驱动

画布上的每个像素、形状、颜色和位置都由哈希值中的具体比特位精确控制。没有随机数，没有预置模板——你的输入就是唯一的美学密码。

🌐

纯前端

所有计算都在浏览器本地完成。使用 Web Crypto API 进行哈希计算，Canvas API 进行图形渲染。无需服务器，你的数据永远不会离开你的设备。
