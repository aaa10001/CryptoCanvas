## ✨ 创意理念

**CryptoCanvas** 是一个将密码学与生成艺术结合的创意开源项目。它的核心思想是：

> **你的输入文本 → SHA-256 哈希 → 独一无二的视觉艺术**

SHA-256 哈希函数具有**雪崩效应**——输入中一个比特的改变，会导致输出中约 50% 的比特发生变化。这意味着：

- `"Hello, World!"` 和 `"hello, world!"` 会生成**完全不同的画作**
- 每个输入都对应**唯一且确定**的艺术作品
- 没有随机数，没有预置模板——**你的输入就是唯一的美学密码**

## 🎨 四种艺术风格

| 风格 | 描述 | 特点 |
|------|------|------|
| **几何抽象** | 同心圆、多边形、线条网络 | 结构感强，色彩鲜明 |
| **流体有机** | 贝塞尔曲线、粒子系统 | 流动感，柔和渐变 |
| **分形树** | 递归分形树结构 | 自然生长感，层次丰富 |
| **万花筒** | 对称扇形、中心辐射 | 对称美学，色彩绚丽 |

## 🧠 技术原理

```
输入文本
    ↓
TextEncoder → UTF-8 字节序列
    ↓
crypto.subtle.digest('SHA-256', data)  ← Web Crypto API
    ↓
256 位哈希值 (32 字节)
    ↓
分解为多个确定性参数
    ├── 色相 (Hue): 0-360°
    ├── 饱和度 (Saturation): 50-90%
    ├── 明度 (Lightness): 40-70%
    ├── 透明度 (Alpha): 0.1-0.8
    ├── 几何参数: 层数、边数、半径、旋转角度
    ├── 分形参数: 分支角度、递归深度、长度比例
    └── 布局参数: 控制点坐标、粒子位置
    ↓
Canvas API 渲染 → 生成艺术
```

### 核心特性

- **🔐 确定性**：相同的输入永远产生相同的画作
- **🌊 雪崩效应**：微小输入变化导致完全不同的输出
- **💻 纯前端**：所有计算在浏览器本地完成，数据不离开设备
- **📦 零依赖**：仅使用 Web Crypto API 和 Canvas API
- **🖼️ 可导出**：支持导出为 PNG 图片

## 🎮 使用指南

1. **输入文本**：在文本框中输入任何文字
2. **生成画布**：点击「生成画布」或按 Enter 键
3. **切换风格**：点击「切换风格」在四种艺术风格间切换
4. **随机输入**：点击「随机」生成随机文本
5. **导出图片**：点击「导出 PNG」保存当前画作
6. **保存记录**：点击「保存」将当前作品存入浏览器本地存储

## 🛠️ 技术栈

- **Web Crypto API** — 浏览器原生 SHA-256 哈希计算
- **Canvas API** — 2D 图形渲染
- **ES6+** — 模块化设计，IIFE 模式
- **CSS3** — 深色主题，响应式设计，渐变动画
